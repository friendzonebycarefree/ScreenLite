# ScreenLite 3

Портативная запись экрана на Windows 11 x64. Для запуска распакуй архив из Releases целиком и открой `ScreenLite.exe`. Соседняя папка `data` содержит компоненты. Видео по умолчанию сохраняется в «Видео\ScreenLite».

- 720p, 1080p и исходное разрешение с сохранением пропорций. 30, 60, 90, 120 и 144 FPS. Запись идёт через DXGI и Media Foundation с аппаратным кодированием при его доступности.
- Окно показывает ожидаемый размер MP4 и приблизительный класс нагрузки. «Лёгкий режим» включает 720p, 30 FPS, компактный профиль и общий звук без обработки. Частота игры, дисплея и кодировщика определяет число уникальных кадров.
- Ctrl+Alt+F9 запускает и останавливает запись. Ctrl+Alt+F10 ставит запись на паузу и продолжает её. Сочетания, угол и непрозрачность мини-панели можно менять в настройках.
- Мини-панель исключается из захвата. Она показывает статус, оценку размера MP4 и сочетания клавиш. В развёрнутом списке можно выключать источники и менять их уровень.
- По умолчанию «Авто» ищет открытые приложения при старте и создаёт дорожки. Если источников не найдено, сохраняется дорожка системного выхода, когда он доступен. Новые приложения вне выбранных деревьев процессов требуют новой записи. Браузерные вкладки обычно объединены. Режим «Общий микс» записывает основной выход Windows одной дорожкой.
- В меню «Звук» можно настроить громкость приложений заранее. Индикаторы «Сигнал» и «С уровнем» реагируют на текущее воспроизведение. Галочка «Автоматически улучшать звук» включает выравнивание громкости, ограничение пиков и фильтр низкочастотного гула микрофона при сохранении.
- Для повторного экспорта оставь папку `.audio` рядом с исходным MP4. В редакторе можно отключить дорожку, изменить её громкость и прослушать фрагмент. Приглушённые до нуля участки не записываются в дорожку. Видеопоток при экспорте копируется. MP4 с общим миксом или без проекта `.audio` не разделяются по приложениям.

## Сборка

Зависимости во время запуска — Microsoft Visual C++ Redistributable x64, Media Foundation и ScreenRecorderLib 7.0.1 (MIT). Код модуля и приложения находится в `data/Source`.

Из корня репозитория в x64 Native Tools Command Prompt:

```bat
cl /nologo /EHsc /std:c++17 /O2 /MD data\Source\ScreenLiteMedia.cpp /Fo:%TEMP%\ScreenLiteMedia.obj /Fe:data\ScreenLiteMedia.exe mfplat.lib mfreadwrite.lib mfuuid.lib ole32.lib
```

Затем из PowerShell:

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /utf8output /target:winexe /platform:x64 /optimize+ /out:ScreenLite.exe /win32manifest:data\Source\ScreenLite.manifest /reference:data\ScreenRecorderLib.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.dll data\Source\ScreenLite.cs data\Source\AudioApps.cs data\Source\AudioProject.cs data\Source\RecordingControls.cs
```
